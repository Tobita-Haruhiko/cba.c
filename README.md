# cba.c
donut.cを参考にアスキーアートとCを用いたロゴアニメーションを作りました。

https://www.a1k0n.net/2011/07/20/donut-math.html
donut.cは基本的な数学を用いることで、回転するドーナツを表示するCのコードです。詳しい解説はこちらのコードを参照してください。

こんぐらいはAIが簡単に生成できてしまいますが、趣旨を考えてあえて手打ちしてみることとしました。

## 基本的な仕組み
### 1. 形を作る
極座標系(r方向、θ方向)それぞれのループで円弧を描き、奥行方向のループで厚みを作ります。
CBAのロゴは4つの円弧で構成されているので、それぞれの半径、円弧の開始と終了の角度、厚み(半径の開始と終了値)を入力してそれぞれ個別に形を作っています。
(donut.cでは極座標系で円を作った後、この円の中心から離れた点を中心にφ方向に回転を行うことで厚みのあるドーナツの形状を作ります)

### 2. 回転し、画面の座標に合わせる
この立体の各点に回転行列を毎フレームかけます。また透視図法をもとにz方向の値に応じたターミナル上での座標への変換を行います。
ターミナルへの座標変換は、何行目の何文字目に文字を置くか、という変換です。

### 3. 光源の設定
光源のベクトル設定し、円弧の外側を向く方向ベクトルとの内積をとることで、そのピクセルがどれぐらい明るいかを計算します。それに応じて表示する文字を変更することで、明るさ、奥行感を出しています。
円弧ではない面の部分は面に垂直な方向のベクトルと光源のベクトルの内積をとるべきですが、面倒だったのと、別にそうしなくても見た目的に耐えたと思ったので、面でも円弧の外側を向く方向ベクトルを使いました。

### 4. グリッチの効果
各行の後に改行を入れないことで、ターミナルのサイズに応じて表示が崩れるようにしました。これが映像におけるグリッチのようなエフェクトの正体です。
